# MDT-Civilian-Data
The MDT that provides a quicker and more efficient method for accessing civilian data, 
enabling easier retrieval of the information needed to perform civil responsibilities.

https://github.com/fnzh-i/MDT-Civilian-Data
---

## 🧩 Project Status
> 🚧 **This project is currently in development.** Certain features and visual elements are still being refined, 
        and additional functionalities will be introduced in future updates.

---

## 🗺️ Roadmap
- [x] **Implement Backend**
  - [x] Design and build RESTful APIs for data access and updates  
  - [x] Connect to a database (e.g., MySQL or MongoDB)  
  - [x] Add authentication and role-based access control  
  - [x] Integrate logging and error handling mechanisms  

- [x] **Implement Frontend**
  - [ ] Design responsive UI using HTML, CSS, and JavaScript (or a framework like React/Vue)  
  - [x] Connect with backend APIs to fetch and display civilian data

  - [ ] Optimize for both desktop and mobile users
